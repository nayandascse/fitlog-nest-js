# Project name
Gym Tracker Plan

# Project Short description

FitLog is a  fitness and workout management web application that helps users discover workouts, create personal workout plans, save favorite exercises, and track their fitness activities.


## Technologies

- Next.js App Router
- React 19 + TypeScript
- Tailwind CSS
- DaisyUI
- React Hot Toast



## 5 key features of the project

- A collection of workouts with details such as duration, difficulty, and muscle groups.

- Add workouts to my personal plan and organize my daily training routine.

- Save workouts for quick access later.

- Manage my saved workout list.

- Easily find workouts by name, category, difficulty, or muscle group.
